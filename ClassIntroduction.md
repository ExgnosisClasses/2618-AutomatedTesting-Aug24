## Course Topics

This is a two-day survey course which means we can't go into detail about individual topics or advanced tool use. We also don't have time to cover the principles and practices of software testing and quality assurance. Selected topics from software testing will be introduced when they are directly relevant to the automation discussion.

The course is divided into six main topic areas:

1. The role of automation in modern software testing
2. Best practices in test automation
3. Unit testing automation
4. Integration testing automation
5. End to end and performance test automation
6. Code quality scanning automation

### Labs

There are four labs scheduled for the course. These labs are intended to provide some practical demonstrations of the tools discussed in class.

The labs do not require any programming experience to execute. 

The main labs are Java based but there are several options for experimenting with Python and Go.
